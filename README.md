# Probiotics Clinical Data Analysis

## Author
Bana Osama  
Biotechnology Engineering Student

## Project Overview
This project explores the relationship between probiotic characteristics 
(dose, duration, and strain) and clinical improvement outcomes using Python.

## Methods
- Data cleaning
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Pearson and Spearman statistical tests
- Linear regression modeling

## Results
The analysis investigated whether probiotic dose and duration 
could predict improvement rate.

## Tools
Python
Pandas
NumPy
